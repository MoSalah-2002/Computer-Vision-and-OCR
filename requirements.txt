## 🎨 What is included

| Area | Experiments |
|---|---|
| 🧩 Image features | VGG19 feature extraction, similarity, and ViT embeddings |
| 🗂️ Clustering | Image clustering with Vision Transformer representations |
| 🔍 Object detection | YOLO-based card and glasses detection experiments |
| 🪪 Document processing | Identity-document preprocessing and OCR/field extraction |
| 🔠 OCR | Arabic/English EasyOCR and PDF text extraction |
| 🌙 Enhancement | OpenCV template matching and Zero-DCE low-light enhancement |

## 🚀 Setup

```bash
git clone https://github.com/MoSalah-2002/Computer-Vision-and-OCR.git
cd Computer-Vision-and-OCR
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
```

Open notebooks in Jupyter or Colab. Object-detection notebooks may require dataset/workspace configuration, and OCR/PDF notebooks may need local image/PDF files and system dependencies such as Poppler.

## 🔐 Security & datasets

Hard-coded API credentials were removed from the prepared notebooks. Configure service keys (for example Roboflow) through environment variables. External datasets, trained weights, and private document images are not included.

## ⚠️ Notes

- These are independent experiments and prototypes, not a unified production pipeline.
- Detection quality depends on the dataset and trained weights used.
- Do not use example document-processing code with real personal documents unless you have appropriate authorization and privacy safeguards.
