## 🚀 Getting started

```bash
git clone https://github.com/MoSalah-2002/Computer-Vision-and-OCR.git
cd Computer-Vision-and-OCR
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
jupyter notebook
```

Several notebooks expect external images, PDFs, datasets, trained weights, or service configuration. These assets are not bundled; read each notebook's setup cells and configure local paths.

## 🔐 Privacy & security

Credentials detected in source notebooks were removed from prepared copies where applicable. Do not upload real identity documents or personal images. Store API credentials in environment variables.

## 📌 Notes

These are standalone experiments rather than a production vision system. Detection and OCR quality depend on training data, model weights, image quality, and preprocessing choices. Not every notebook has been executed end-to-end in a clean environment.
